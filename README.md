# 百鬼夜行 - HYAKKI YAGYO

和風ディアブロ風ハクスラ（ハック＆スラッシュ）。妖を斬り、階層の深奥へ潜る見下ろし型アクションRPG。
**グラフィックは稚拙なCanvas図形描画**ですが、武器・レアリティ・アフィックス・レベルの加護・永続強化など、ハクスラ/ローグライトの「いいとこどり」を詰め込んでいます。

## 遊び方（iPhone）

1. Safari で公開URLを開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動（全画面・オフラインでも動作）

左の仮想スティックで移動、右下の **斬** で攻撃、**疾** でダッシュ。
PC: `WASD` 移動 / `J`・クリック 攻撃 / `K`・`Shift` ダッシュ。

## 収録要素

- **和風武器 18 種**: 木刀 / 打刀 / 太刀 / 小太刀 / 忍者刀 / 薙刀 / 鑓 / 十手 / 鎖鎌 / 金棒 / 和弓 / 手裏剣 / 苦無 / 鉄扇 / 錫杖 / 火縄銃 / 御幣 / 数珠
- **レアリティ 6 段階**: 並・良・名・秘・神・妖（+ ランダムアフィックス最大 5）
- **敵 11 種 + ボス 5 種**: 子鬼・鬼・天狗・河童・妖狐・雪女・からかさ小僧・骸骨武者・土蜘蛛・鵺・ろくろ首 / 酒呑童子・大天狗・九尾の狐・般若・八岐大蛇
- **レベルの加護 20 種**（3 択）、**護符 10 種**（3 スロット）
- **神社の永続強化 6 種**（localStorage に保存）
- ランダムドロップ、会心、属性、吸血、爆発、連鎖雷、鳥居で次部屋へ

## GitHub Pages での公開

1. このフォルダの中身をリポジトリ直下に push
2. Settings → Pages → Source: `Deploy from a branch` / Branch: `main` / `/ (root)`
3. 数十秒後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

PWA（ホーム画面追加）は HTTPS 配信でのみ有効です。GitHub Pages は HTTPS なので条件を満たします。
